## 🚀 Featured Projects

### 🧠 AI Cluster Scheduler 🔒
*Graduation project · Python · Reinforcement Learning · pytest · 2026 – present*

A Python simulator of a heterogeneous CPU/GPU cluster, modeled as a Markov decision process and driven by real job traces from the college's computing cluster. Built in a two-person team under academic supervision.
- Baseline scheduling policies (FIFO, SJF, type-aware Greedy, EASY Backfilling) behind a shared policy interface
- Evaluation pipeline across multiple random seeds, reporting makespan, waiting time and slowdown with 95% confidence intervals
- Automated tests with pytest
- Next phase: a deep RL agent (Deep Q-Learning, PUCT) benchmarked against the baselines

> The repository is private for now (graduation project). Code and a demo are available on request.

### ⚙️ [Multi-Process Graph Traversal Simulator](https://github.com/Omar-Aqel/OS_Project_2026)
*Operating Systems · C · POSIX · Linux · raylib · 2026*

A C simulation of travelers moving along Dijkstra shortest paths in a weighted graph, with a real-time raylib GUI. Built in a 4-person team.
- Each traveler runs as its own process (fork, signals, waitpid) and reports over non-blocking pipes
- POSIX semaphores in shared memory (mmap) enforce one traveler per node
- User-space scheduler comparing FCFS and SJF for waiting time and starvation
